### Hướng dẫn cài đặt
- Step 0: Install NodeJS and PostgreSQL
- Step 1: Copy .exv.example to .env
- Step 2: Create database "vcb" in PostgreSQL
- Step 3: ```npm install```
- Step 4: ```npm run build```
- Step 5: ```npm run start```

### Hướng dẫn cài đặt với Docker
- Step 1: comment DATABASE_URL ở mục Nondocker + xóa comment DATABASE_URL ở mục Docker
- Step 2: ```docker compose up --build```
